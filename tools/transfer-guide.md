# Tongumble — Windows 이전 패키지

## 새 PC에서 바로 플레이

1. ZIP을 USB·클라우드로 새 PC에 복사합니다.
2. ZIP 안에서 실행하지 말고 **압축을 모두 풀어** 쓰기 가능한 폴더에 둡니다. 폴더 이름에 한글·공백이 있어도 됩니다.
3. `START-GAME.cmd`를 더블클릭합니다. 기본 브라우저가 `http://127.0.0.1:5280/`를 엽니다. Chrome 또는 Edge에서 플레이합니다.
4. 실행 창은 켜 둡니다. 종료는 창에서 Ctrl+C입니다. 포트가 이미 사용 중이면 앞서 연 실행 창을 닫고 다시 시작합니다.

게임 실행에는 설치·인터넷·Codex 계정이 필요 없습니다. Windows x64용 Node 실행 파일을 포함했습니다. 압축 폴더의 `game/index.html`을 직접 여는 대신 시작 파일을 사용하세요.

## 현재 플레이도 이어가기

브라우저 저장은 PC·브라우저 프로필·서버 주소마다 다릅니다. 소스 ZIP에는 현재 사용자 브라우저의 실제 저장이 자동 포함되지 않습니다.

1. **현재 PC의 게임에서 설정 → 저장 내보내기**를 누릅니다. `frog-ascent-backup-날짜.json`을 받습니다.
2. JSON도 ZIP과 함께 새 PC로 옮깁니다.
3. 새 PC 게임에서 **설정 → 저장 가져오기**로 JSON을 선택하고 **계속 오르기**를 누릅니다. 위치·속도·혀 연결·먹힌 파리·이동 위상·기록·설정을 복구합니다.

연습 모드는 본 코스 저장을 덮어쓰지 않습니다. 기존 진행이 있다면 가져오기 확인창이 나오며 기존 진행을 이전 기록으로 보관합니다. 잘못된 파일은 현재 저장을 바꾸지 않습니다. 현재 PC에서 개발 주소(5173)와 실행 주소(5280)를 바꿀 때에도 같은 내보내기/가져오기를 사용하세요.

## 다른 계정에서 계속 개발

`workspace/Last` 폴더를 새 Codex 계정의 프로젝트로 엽니다. 최상위 `HANDOFF.md`에 현재 구현·파일 구조·검증·남은 작업·다음 계정에 전달할 문장이 있습니다. Codex 대화 자체와 로그인은 이 ZIP으로 자동 이전되지 않습니다.

- `DEVELOP.cmd`: 포함된 Node·pnpm으로 소스 의존성을 고정 버전으로 설치하고 개발 서버(5173)를 엽니다. 첫 설치는 인터넷이 필요합니다.
- `BUILD-GAME.cmd`: 테스트와 빌드 성공 후 `game`을 갱신합니다. 실행 중인 게임을 먼저 닫고 사용하세요.
- `runtime/node.exe`와 `runtime/pnpm/bin/pnpm.mjs`: 다른 Windows 사용자 이름에 의존하지 않는 실행 도구.
- `workspace/Last/planning`, `refs`: 기획서·원본 참고 영상·프레임·조사. 참고 자료는 게임 안에 배포되는 아트 에셋이 아닙니다.
- `workspace/1006/openspec`, `.agents/skills`: 이 게임의 이전 제안과 사용한 OpenSpec 워크플로.
- `licenses`: 포함한 런타임·라이브러리의 라이선스.
- `MANIFEST.sha256`: 파일 무결성 검사 목록. 필요하면 PowerShell `Get-FileHash -Algorithm SHA256`으로 비교합니다.

원본 코드는 모두 포함하며 `node_modules`·브라우저 캐시·다른 Unity 프로젝트·계정 인증 정보는 포함하지 않습니다. 새 PC에는 최신 Chrome/Edge와 WebGL을 지원하는 그래픽 환경이 필요합니다. 현재 버전의 전체 180m 사람 완주·실제 패드·모든 PC 성능 검수는 아직 완료되지 않았습니다.
